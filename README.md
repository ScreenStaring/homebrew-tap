# ScreenStaring's Homebrew Tap

```
brew tap screenstaring/tap
```

## Formulas

### [Shopify Development Tools](https://github.com/ScreenStaring/shopify-dev-tools/)

Command-line program to assist with the development and/or maintenance of Shopify apps and stores.

```
brew install shopify-dev-tools
```

### [Tiendanube Development Tools](https://github.com/ScreenStaring/tiendanube-dev-tools/)

Command-line program to assist with the development and maintenance of Tiendanube and Nuvemshop apps and stores.

```
brew install tiendanube-dev-tools
```
